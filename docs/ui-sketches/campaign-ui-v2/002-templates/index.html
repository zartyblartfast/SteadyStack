Value zone shorthand

P10 means Bitcoin is historically cheap

P10 means the BMRI reading is in the cheapest 10% of historical readings in the available dataset, relative to long-term Bitcoin value anchors. P5 is an even deeper value zone. The exact history range depends on the BMRI data source.
